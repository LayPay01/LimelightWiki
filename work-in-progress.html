WHAT WE ARE WORKING ON

A living snapshot of every major Limelight component: what already works, what is being tested, and what the next honest milestone looks like. This is a development record, not a promise of release dates.

The Short Version

Limelight is no longer one project moving in one straight line. The main app is preparing its next Early Access line while Stagehand, ArenaKit and LimelightMP prove separate runtime and authoring systems. Probe is the newest component and the only brand-new application currently being built.

BUILDING NOW Limelight Probe A bounded game-behaviour capture and discovery tool.
MAIN RELEASE LINE Limelight 0.2.0 Early Access Reliability, Stagehand integration and existing feature polish.
LIVE SCRIPTING PROTOTYPE Stagehand 0.5.1 / API 1.3 Proven events, bounded HUD actions and a working proof mod.
ARENA TOOLING ArenaKit 0.3.0 Direct project cooking with legacy repair retained as an advanced path.
Building now Prototype or testing Usable or maintenance Approved roadmap
HOW TO READ THIS PAGE

“Proven” means a path has passed the recorded build, fixture or live-game test described by its project. It does not mean every mod, map, machine or game update is guaranteed to work.

Being Built Right Now

Limelight Probe

Building now

Probe records a short, deliberately bounded window around one in-game action and ranks the objects, properties and calls that changed. Its purpose is to turn noisy Unreal discovery into evidence a modder can actually inspect.

RELEASE NO RELEASE YET
CURRENT PHASE RUNTIME OBSERVER
  • Analysis, diff, ranking and redacted export core in place
  • WPF capture controller and report viewer in place
  • Fixture runner for deterministic testing
  • Separately installable, capped UE4SS observer now being built
  • Unconfirmed Stagehand adapter suggestions

The Main Limelight Runtime Family

Limelight

Integrating

The main desktop app remains the player-facing centre of the family: importing, profiles, compatibility, launch modes, Live Loader, X19, multiplayer setup and Stagehand management.

VERSION LINE 0.2.0 EARLY ACCESS
PRIORITY RELIABILITY
  • Integrate Stagehand install, update and health reporting
  • Keep archive importing and target detection dependable
  • Harden Live Loader switching and recovery
  • Keep future systems behind current release work

Native Bridge

Maintenance

The bridge performs the focused Unreal work Limelight cannot do from outside the game: mounting IoStore containers, managing package state and refreshing active meshes, materials and textures.

VERSION 0.1.13
DISTRIBUTION BUNDLED WITH LIMELIGHT
  • Known runtime path is established
  • Updated only when a proven Limelight operation needs it
  • Not intended as a separate user download

X19 LLoader

Usable feature

X19 builds on the normal Live Loader and adds ordered or shuffled character rosters that can be changed through keyboard or controller input without returning to Limelight.

HOME INSIDE LIMELIGHT
NEXT EXPERIMENT TAG TEAM
  • Continue using the normal safe activation path
  • Maintain profile, shuffle and controller behaviour
  • Tag Team remains planning only, not an implemented mode

LimelightMP

Experimental

The host, client, authenticated relay and player-two controller path work as a prototype. Both PCs render the replicated world locally; this is not a video-streaming system.

VERSION 0.1.0
CURRENT GOAL FULL-SESSION RELIABILITY
  • Harden level and sublevel travel
  • Improve cameras, dialogue and player-local menus
  • Stabilise rhythm, audio, effects and frame times
  • Build Handshake only after normal sessions are dependable

Creator and Authoring Tools

Limelight Stagehand

Live prototype

Stagehand is the gameplay-mod scripting SDK and authoring workbench. Logic mods subscribe to a versioned event/action API rather than depending directly on fragile Unreal names.

VERSION 0.5.1 / API 1.3
LIVE PROOF PERFECT CHARGE
  • Proven beat, arena and perfect-input paths
  • Bounded notifications, beat cue and namespaced HUD meter
  • Permissions, capabilities, dependencies and health report
  • Good/player-facing Beat detection remains unproven
  • Choreographer follows after the SDK and script workflow settle

Limelight ArenaKit

Community testing

ArenaKit provides a current Unreal Engine 5.7 route for building new arenas and recovering compatible older editable projects without distributing extracted game assets.

VERSION 0.3.0
DEFAULT PATH DIRECT PROJECT COOK
  • Test direct cooking against more independent projects
  • Prove base-game static-mesh references in a live arena
  • Expand streamed recovery only where reconstruction is safe
  • Keep Legacy Repair as the advanced fallback

Model Migrator

Usable tool

Model Migrator updates older Charlie replacement projects for the current split mesh layout and can optionally cook and package a selected mod.

VERSION 0.1.0
CURRENT STATE MAINTAINED
  • Multi-mod projects and automatic dedicated chunks
  • Optional glasses PABP and complete No Hair source set
  • Patch-only and patch-plus-package workflows
  • Backups before migration and packaging changes

Choreographer

Approved roadmap

Choreographer will be Stagehand's visual, no-code authoring view. It is deliberately not a separate app or runtime and will compile to the same validated Stagehand Lua contract.

IMPLEMENTATION NOT STARTED
DEPENDENCY STABLE SDK
  • Shared graph model and deterministic Lua compiler first
  • Canvas, blocks, templates and generated-Lua preview later
  • Only expose actions backed by proven Stagehand contracts

Roadmap Order

The projects share infrastructure, but they do not all advance at once. The current planning order keeps new concepts behind the reliability of the systems they need.

Now

Build Probe; integrate and test Stagehand; prepare Limelight 0.2.0 Early Access; continue ArenaKit and LimelightMP reliability work.

Next proofs

Stagehand SDK stability, ArenaKit community project coverage and real base-mesh loading, plus dependable full-session multiplayer travel and presentation.

Shared foundation

Define Passport identity data, then let Patchwatch and Handshake consume the same normalized mod record.

Future gameplay

Choreographer and Tag Team only begin after their required Stagehand and Live Loader paths are proven. Booth, Conductor and Stems remain exploratory.
